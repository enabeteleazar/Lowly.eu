Architecture

Pret pour un hebergement statique

Le site ne depend plus de PHP, d'un ancien CMS, de scripts publicitaires ou de ressources externes non maitrisees. Les pages sont servies directement en HTML, CSS et JavaScript minimal.

Cette base peut etre deployee sur Vercel, Netlify, Nginx, Apache ou n'importe quel hebergement capable de servir des fichiers statiques.
